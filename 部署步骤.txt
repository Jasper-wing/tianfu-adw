====================================================
  把网站放到云端（Streamlit 官方免费云）—— 照着点就行
====================================================

【需要上传的文件】就在本文件夹 deploy 里，共 4 个：
  app.py
  engine.py
  radar.py
  requirements.txt
（README.md 可传可不传）

----------------------------------------------------
第一步：在 GitHub 建仓库
----------------------------------------------------
1. 打开 github.com，登录你的账号。
2. 点右上角头像左边的【 + 】号，选【 New repository 】。
3. Repository name 填：tianfu-adw
   （必须全小写英文，不能有空格、不能中文）
4. 下面选【 Public 】（公开）。
5. 点绿色按钮【 Create repository 】。

----------------------------------------------------
第二步：把 4 个文件传上去
----------------------------------------------------
1. 新仓库页面中间，点蓝色链接【 uploading an existing file 】。
2. 打开本 deploy 文件夹，把 4 个文件
   （app.py、engine.py、radar.py、requirements.txt）
   一起选中，拖进网页中间写着 Drag files here 的虚线框。
3. 等它显示 4 个文件都绿勾了，点绿色按钮【 Commit changes 】。

----------------------------------------------------
第三步：连到 Streamlit 云
----------------------------------------------------
1. 打开 share.streamlit.io，点【 Continue with GitHub 】，
   授权登录（用你刚才那个 GitHub 账号）。
2. 点右上角【 Create app 】（或 New app）。
3. 三个框这样填：
   - Repository：选 你的用户名/tianfu-adw
   - Branch：main
   - Main file path：app.py
4. 点【 Deploy! 】。

----------------------------------------------------
第四步：拿到链接
----------------------------------------------------
1. 等 1~2 分钟，页面顶部出现一个链接，形如：
   https://你的用户名-tianfu-adw.streamlit.app
2. 把这个链接发给任何人（微信/QQ 都行），
   对方点开就能用，你电脑关机也不影响。

----------------------------------------------------
注意（务必看）
----------------------------------------------------
* 免费版应用是【公开】的，任何人都能打开。
* 长时间没人点会【休眠】，别人第一次打开要等几十秒自动唤醒，属正常。
* 以后改了 app.py，在 GitHub 仓库里把新文件替换掉、
   重新 Commit，Streamlit 会自动重新部署，链接不变。

----------------------------------------------------
如果哪一步卡住，把网页上出现的英文提示发我，我帮你看。
