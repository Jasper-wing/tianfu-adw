# 天府机场混合跑道独立进近 · 碰撞风险评估与避让调度

「第一届大学生交通运输实践创新大赛」参赛作品 —— 成都天府国际机场「平行 + 开口 V 型」混合跑道独立进近的**碰撞风险评估与冲突避让动态调度**演示工具。

## 功能页签

1. **碰撞风险与 ADW 下边界** —— 遍历改出角 × 避让距离 L1 × 起飞时刻，计算 `P = Px·Py·Pz·N`，反推满足 TLS = 5×10⁻⁹ 的 ADW 下边界；含风险分量分解、风险 vs 改出角、风险 vs 起飞时刻（最不利起飞时刻）等分析曲线。
2. **尾流 / 改出角** —— 两机水平接近时的最小垂直高度差，与 300 m（1000 ft）阈值比较。
3. **三维航迹** —— 进近避让机与离场机的三维轨迹交互可视化。
4. **雷达数据导入** —— 上传雷达 SQL 与呼号表，统计进近误差 / 一边误差 / TT465 高度 / 8 个进近区域。
5. **复飞（定点 vs 定高）** —— 两种转弯方式的复飞碰撞风险与最小间距对比。

## 在线体验

> 部署后此处填 Streamlit 云链接，例如 `https://<用户名>-<仓库名>.streamlit.app`

## 本地运行

```bash
pip install -r requirements.txt
streamlit run app.py
```

浏览器自动打开 `http://localhost:8501`。

## 文件说明

| 文件 | 作用 |
|------|------|
| `app.py` | Streamlit 主界面（5 个页签） |
| `engine.py` | 碰撞风险引擎（参数化重构，修正原始笔误） |
| `radar.py` | 雷达航迹解析与误差统计 |
| `requirements.txt` | Python 依赖 |

## 依赖

Python 3.9+，依赖见 `requirements.txt`（streamlit / numpy / scipy / pandas / plotly / openpyxl）。
